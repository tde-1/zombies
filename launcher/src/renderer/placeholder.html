Pointing it somewhere

The launcher tries these in order and uses the first that answers:

  • http://127.0.0.1:8099 and :3000 — the ENW Zombies site (web/)
  • http://127.0.0.1:8080 — the mock site (infra/host-agent/mock-site)
  • http://127.0.0.1:8787 — the host agent's dashboard

Pin one in Settings, or set ENW_SITE_URL before starting the launcher.
